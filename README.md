# C-Pattern-Programs

Collection of Pyramid Pattern Programs in C language - created for logic building using loops.

## Patterns Included
- Half Pyramid Star - `half_pyramid_star.c`
- Inverted Half Pyramid of Numbers - `inverted_half_pyramidofnumbers.c`
- Inverted Full Pyramid of Star - `inverted_full_pyramidofstar.c`
- Full Pyramid of Alphabets - `full_pyramid_of_alphabets.c`

## Concepts Used
- Nested for loops
- printf formatting
- Logic building for placement interviews

## Language
C Language
